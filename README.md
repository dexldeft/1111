# КонспектДроп - веб-портал для обмена учебными конспектами

Ссылка на работающий сайт: https://konspektdrop.onrender.com

## О проекте
КонспектДроп - это веб-сайт, на котором учащиеся могут делиться своими конспектами с лекций. Пользователи загружают файлы по определенным предметам, а другие студенты могут их просматривать и скачивать.

## Проблема
Учебные материалы часто разбросаны по разным чатам, облачным дискам и личным заметкам.

## Цель
Создать единую централизованную платформу для хранения, поиска и обмена конспектами, где каждый учащийся сможет быстро найти нужный материал или выложить свой.

## Основные функции первой версии
- Регистрация и вход: Создание аккаунта и авторизация с возможностью запомнить сессию.
- Каталог предметов: Просмотр конспектов, отсортированных по 20 учебным дисциплинам.
- Загрузка файлов: Возможность прикреплять к посту файлы форматов PDF, DOC/DOCX, PNG, JPG.
- Личный кабинет: Раздел «Мои конспекты» и история «Просмотренные».
- Модерация: Новые конспекты уходят на проверку администратору (статусы: «На проверке», «Опубликован», «Отклонен»).
- Админ-панель: Управление очередью модерации, просмотр всех постов и управление пользователями (блокировка, удаление).

## Ограничения первой версии
- Нет функции восстановления пароля.
- Нет редактирования профиля пользователя (смены пароля или аватара).
- При редактировании конспекта нельзя заменить прикрепленный файл (меняется только тема и описание).
- Поиск осуществляется только по карточкам предметов, нет глобального поиска по названию темы.

## Инструкция по запуску
1. Клонируйте репозиторий.
2. Установите зависимости: `pip install -r requirements.txt`.
3. Настройте переменные окружения (SUPABASE_URL, SUPABASE_KEY, DATABASE_URL, SECRET_KEY).
4. Запустите сервер: `python app.py`.
5. Сайт будет доступен по адресу: `http://127.0.0.1:5000`.
